# IP Calculation

For calculating allowd IPs for host use this formula:

2^(zero bits) - 2

Example:
Subnet mask = 255.255.255.0
Zero bits = 8

==> 2^(8) - 2 = 254  

Example:
Subnet mask = 255.255.248.0
Zero bits = 11

== > 2^(11) - 2 = 2,046
